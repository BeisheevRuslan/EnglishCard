# EnglishCard — Приложение для изучения английского языка

> Курсовая работа по курсу «Базы данных»

---

## Описание проекта

**EnglishCard** — это веб-приложение для изучения английских слов, разработанное с использованием Python, Streamlit и PostgreSQL. Приложение позволяет пользователям проходить викторины, добавлять персональные слова в словарь и отслеживать прогресс изучения.

---

## Возможности приложения

| Функция | Описание |
|---------|----------|
| **Викторина** | Проверка знаний с 4 вариантами ответа |
| **Добавление слов** | Персональный словарь пользователя |
| **Удаление слов** | Управление личным словарём |
| **Статистика** | Точность, попытки, прогресс изучения |
| **Схема БД** | Просмотр структуры базы данных |

---

## Требования

Для работы приложения необходимо установить:

- **Python 3.12+**
- **PostgreSQL 14+**
- **Виртуальное окружение** (venv)

---

## Установка и запуск

### Шаг 1: Клонируйте репозиторий
```bash
git clone <ссылка-на-репозиторий>
cd <папка-проекта>
```

### Шаг 2: Создайте виртуальное окружение
```bash
python -m venv .venv
```

### Шаг 3: Активируйте виртуальное окружение
```bash
.venv\Scripts\activate
```

### Шаг 4: Установите зависимости
```bash
pip install -r requirements.txt
```

### Шаг 5: Создайте базу данных в PostgreSQL
```sql
CREATE DATABASE english_card;
```

### Шаг 6: Настройте подключение к БД
В файле main.py проверьте параметры подключения в функции get_db_connection():
```python
def get_db_connection():
    return psycopg2.connect(
        host="localhost",
        database="english_card",
        user="postgres",
        password="postgres"  # Замените на ваш пароль
    )
```

Шаг 7: Запустите приложение
```bash
streamlit run main.py
```

Приложение откроется в браузере по адресу: http://localhost:8501
